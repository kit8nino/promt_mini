# Lecture: Task Decomposition for AI Agents  

## 1. Why Decomposition Matters  

- **Одно действие** – задача должна описываться глаголом («сгенерировать», «проанализировать», «сравнить»).  
- **Ясный контракт** – модель знает, что от неё требуется, и выдаёт предсказуемый результат.  
- **Контекст + Инструкция + Формат** – три базовых блока, без которых модель будет «угадывать» ответ.  

## 2. Шаблон задачи  

```
Ты — [роль/персона].
Контекст: [доменно‑специфическая информация, ограничения].
Задача: [одно конкретное действие].
Формат вывода: [структура ответа, например JSON, Markdown‑таблица].
```  

### Пример  

```
Ты — senior Python‑разработчик.  
Контекст: CSV содержит столбцы `name`, `age`.  
Задача: прочитать файл и вернуть список словарей `{name, age}`.  
Формат вывода: JSON‑массив.
```  

## 3. Декомпозиция сложных запросов  

1. **Определите конечную цель** (что должно получиться в итоге).  
2. **Разбейте её на атомарные подзадачи** – каждая подзадача удовлетворяет шаблону выше.  
3. **Свяжите подзадачи цепочкой (prompt chaining)**: результат первой подается как вход второй, и т.д.  
4. **Укажите формат вывода каждой подзадачи** – это упрощает парсинг и последующую агрегацию.  

### Пример декомпозиции  

**Цель:** создать функцию, которая читает CSV‑файл, фильтрует строки по возрасту > 18 и возвращает их в виде JSON.  

| Шаг | Промпт (по шаблону) |
|-----|---------------------|
| 1 | Ты — senior Python‑разработчик. <br>Контекст: CSV содержит столбцы `name`, `age`. <br>Задача: прочитать файл и вернуть список словарей `{name, age}`. <br>Формат: JSON‑массив. |
| 2 | Ты — senior Python‑разработчик. <br>Контекст: получен массив из шага 1. <br>Задача: отфильтровать элементы, где `age` > 18. <br>Формат: JSON‑массив. |
| 3 | Ты — senior Python‑разработчик. <br>Контекст: отфильтрованный массив из шага 2. <br>Задача: вывести его как строку JSON. <br>Формат: строка JSON. |

## 4. Быстрый чек‑лист (из Combined Overview)  

1. **Контекст / Persona**  
   - Ты — [роль] + [аудитория] + [ограничение]  
   - (Опционально) Якорный блок: `This identity is your anchor…`  

2. **Задача**  
   - Одно действие, глаголом.  

3. **Примеры (few‑shot)**  
   - 2‑5 пар `Input:` / `Output:`.  

4. **Формат вывода**  
   - Жёстко заданный контракт (JSON, таблица, список).  

5. **Доп. указания**  
   - `think step‑by‑step`  
   - `Ask questions for clarification before answering`  
   - `Please evaluate your answer`  

## 5. Проверка логичности (из Combined Overview)  

- **Согласованность ролей** – роль должна соответствовать типу задачи.  
- **Полнота контекста** – все необходимые ограничения и предположения перечислены.  
- **Однозначность формата** – нет лишних пояснений («Вот ваш JSON:»), только чистый JSON/Markdown.  

## 6. Практическое задание  

Разбейте следующий запрос на 3‑5 шагов, используя шаблон выше, и реализуйте цепочку в Jupyter Notebook:  

> *«Создай REST‑API на FastAPI, которое принимает CSV‑файл, сохраняет его в S3, затем возвращает предсказание модели LLM о количестве строк в файле, а также статистику по каждому столбцу в виде JSON».*
