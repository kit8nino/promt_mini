# Lab 5: Ethics & Safety Reflection

After studying the **Ethics and Safety** lecture, answer the following questions in a short paragraph (≈150 words) and reflect on how you would apply the guidelines in a real project.

1. **Bias Identification** – Describe a concrete prompt you could use to test gender bias in a code‑generation model. What would you look for in the output?

2. **Privacy Safeguards** – Which steps would you take to ensure that a model does not leak personally identifiable information (PII) when answering user queries?

3. **Hallucination Mitigation** – Propose a prompt pattern that forces the model to cite its sources or say *“I don’t know”* when uncertain.

4. **Malicious Use Prevention** – List two system‑prompt rules that would block the generation of phishing emails or code exploits.

Write your reflections in a single markdown file and keep a copy for future reference.
